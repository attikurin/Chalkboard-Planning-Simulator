板書計画シミュレーター (Board Plan Simulator)

授業前の「板書計画（万象）」をデジタル上で効率的に作成・試行錯誤するためのWebアプリケーションです。
「ノートに書いては消す」というアナログな作業をデジタル化し、複数の案を比較検討したり、作成した計画を印刷・保存したりすることができます。

📌 特徴

黒板/ホワイトボード切替: 授業スタイルに合わせてワンクリックで背景と配色を変更可能。

直感的な操作: マウスやタッチ操作による「チョーク風の手書き」に加え、テキスト入力や図形配置も可能。

スナップショット比較: 「導入案」「展開案」など、作成途中の盤面を一時保存し、瞬時に切り替えて比較・復元できます。

教育現場特化: 余計な機能を削ぎ落とし、現場で必要な機能（色使い、グリッド、印刷）に絞り込みました。

インストール不要: HTMLファイル1つで動作するため、複雑なセットアップは不要です。

🚀 使い方

ファイルの開き方

board_simulator.html をモダンブラウザ（Chrome, Edge, Safari, Firefoxなど）で開いてください。インターネット接続があれば、必要なライブラリを自動的に読み込んで起動します。

基本操作

書く: 左サイドバーの「ペン」アイコンを選択し、キャンバス上をドラッグします。

文字を入れる: 「T」アイコンをクリックし、テキストを入力します。確定後は「選択（矢印）」ツールで移動や拡大が可能です。

消す: 「消しゴム」アイコンを選択し、消したいオブジェクトをクリックします。

案を保存する: 右サイドバーの「＋保存」ボタンを押すと、現在の状態がサムネイルとして記録されます。サムネイルをクリックするとその状態に戻ります。

⚠️ 注意事項

ブラウザのローカルストレージやサーバーへの保存機能は実装されていません。ブラウザを閉じると内容はリセットされます（画像として保存することをお勧めします）。

タッチデバイス（タブレット等）でも動作しますが、ペンタブレットやApple Pencil等の筆圧感知には現在対応していません。
